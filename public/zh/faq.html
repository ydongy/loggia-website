常见问题

没找到答案？App 会直接告诉你哪里出了问题、点哪个按钮能修好，先打开服务或链路详情看看。

基本

Loggia 免费吗？

免费版免费，最多可以公开 2 个服务到互联网，但不能新开访问保护。Pro 取消这些限制，一次买断。详见价格。

需要准备什么？

一台 macOS 26 或更高版本的 Mac、一个 Cloudflare 账户，以及至少一个由 Cloudflare 托管的域名。

需要给 Cloudflare 付费吗？

公开服务用的是 Cloudflare Tunnel，它是免费的。访问保护需要账户开通 Zero Trust，免费套餐就够用。域名照常由注册商收费。

Mac 需要一直开着吗？

需要。服务一直运行在你的 Mac 上，Loggia 只是给它们一个公网地址。Mac 睡眠、关机或断网时，地址就访问不到。连接器会在登录时自动启动，Mac 恢复后服务也随之恢复。

访问流量会经过你们的服务器吗？

不会。访客通过 Cloudflare 直接访问你 Mac 上的服务。Loggia 没有自己的服务器，也看不到你的流量。详见隐私政策。

Cloudflare 与 API 令牌

API 令牌需要哪些权限？

在引导或「设置 › Cloudflare」里点 在 Cloudflare 创建 Token，会打开一个已经勾好权限的模板，直接确认即可。模板包含：

Account › Cloudflare Tunnel › Edit必需
Zone › DNS › Edit必需。Zone Resources 可以只选要用的域名。
Account › Access: Apps and Policies › Edit可选，用于访问保护
Account › Access: Organizations, Identity Providers, and Groups › Edit可选，让 Loggia 自动设置邮箱验证码登录

如果想自己创建令牌，「设置 › Cloudflare」里逐项列出了权限，并提供 复制权限清单。令牌只保存在 Mac 的钥匙串里。

刚在 Cloudflare 补了权限，Loggia 还是提示缺少权限。

Cloudflare 上的改动要一两分钟才生效。稍等片刻，再到「设置 › Cloudflare」点 重新检查。

为什么开不了访问保护？
  • 访问保护是 Pro 功能。
  • 服务要先公开，才能开启访问保护。
  • 令牌需要带上面列出的两项 Access 权限。
  • Cloudflare 账户需要开通 Zero Trust，免费套餐就够用。开通后到「设置 › Cloudflare」点 重新检查。
开启访问保护后，谁能打开我的服务？

只有你列出的邮箱；添加 @example.com 则允许该域名下的所有邮箱。访客会通过邮件收到一次性验证码。登录默认有效 24 小时，可以调整。

Pro 还可以添加受信任的网络，比如家里或办公室的公网地址。从受信任网络访问时不需要验证码，同一 Wi-Fi 或移动网络里的其他人也一样。

Loggia 会覆盖我正在使用的域名吗？

不会悄悄覆盖。如果域名已经指向别处，Loggia 会停下来，先征得你的同意再做改动。

Pro 与许可

一个授权码能用在几台 Mac 上？

两台。想换到另一台 Mac，先在已激活的其中一台上，到「设置 › 许可」点 取消激活。

Pro 需要联网吗？

激活时需要。之后 Loggia 每天验证一次授权；连不上授权服务器时，Pro 从上次验证成功起还能继续用 30 天，Mac 联网后会自动恢复。

授权码覆盖哪些版本？

1.x 的全部版本。更新本身对免费版和 Pro 都是免费的。

可以退款吗？

可以，购买后 14 天内。退款政策里写明了如何申请，以及授权码会怎样。

退款后，或者授权失效后会怎样？

Loggia 回到免费版，但不会下线任何东西：已经公开的服务继续运行。免费版只管理列表里最早公开的 2 个服务；其余的继续运行，但 Loggia 不再检查它们，并显示为 未管理，你仍然可以停止公开。已经开启的访问保护继续生效，可以关掉，但不能再修改。重新升级到 Pro 后一切恢复。

故障排查

服务显示不在线，从哪里开始查？

打开这个服务。Loggia 会显示链路的哪一段断了（本地服务、域名记录、Mac 上的连接器，还是 Cloudflare）、原因是什么，以及点哪个按钮能修好。新的域名记录可能要几分钟才生效。

Loggia 提示有代理软件拦截了连接。

代理软件在增强模式或 TUN 模式下开着 Fake-IP 时，会给 argotunnel.com 返回假地址，cloudflared 到 Cloudflare 最多只能保持两条连接，甚至连不上。cloudflared 连不上 Cloudflare 时，Loggia 会检查这一点，确认之后才提到代理软件。在代理软件里：

  1. 把 argotunnel.com 和 cftunnel.com 设为直连。
  2. 把 +.argotunnel.com 加入 Fake-IP 过滤（fake-ip-filter），让它解析到 Cloudflare 的真实地址。Fake-IP 模式下只设直连还不够。
  3. 点 Loggia 显示的 重新连接、重试 或 重启。

公开服务的状态是从外网检查的，不受代理软件影响。如果刚公开的域名在别处能打开、在这台 Mac 上打不开，可能是代理软件把它记成了不存在，最长半小时：把这个域名也加入 Fake-IP 过滤，或者清一次代理软件的 DNS 缓存。

在哪里查看连接器的状态？

「设置 › 连接器」会显示 cloudflared 是否已安装、是否在运行、版本、上次退出码和日志。如果一直出错，可以在那里导出诊断信息。

更新与卸载

怎么更新 Loggia？

Loggia 每天自动检查一次新版本。有新版本时，会显示更新内容，并可以帮你下载、安装和重新打开。想马上检查，在「设置 › 关于」里点 检查更新；不想每天自动检查，在同一处关掉 自动检查更新。设置和服务都会保留，免费版和 Pro 都可以免费更新。每个版本改了什么，见更新日志。

怎么彻底卸载 Loggia？
  1. 在「设置 › Cloudflare」里点 彻底移除…，先清掉 Loggia 在 Cloudflare 上的域名记录、路由和访问保护。
  2. 退出 Loggia，把它从「应用程序」移到废纸篓。
  3. 在终端运行 launchctl bootout gui/$(id -u)/com.useloggia.app.cloudflared，然后删除 ~/Library/Application Support/Loggia、~/Library/Logs/Loggia 和 ~/Library/LaunchAgents/com.useloggia.app.cloudflared.plist。
  4. 在「钥匙串访问」里删除「Loggia」条目。
