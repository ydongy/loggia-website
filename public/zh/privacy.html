隐私政策

最后更新 · 2026 年 10 月

本页译文仅供参考；如与英文版本不一致，以英文版本为准。

本政策适用于 Loggia 应用和本网站：收集什么、发送给谁，以及你有哪些选择。

1. 我们收集什么

激活、验证或取消激活 Pro 时，Loggia 会通过 HTTPS 向 Dodo Payments 发送授权码和一个设备标签（你的 Mac 名称加一段由硬件标识算出的短码）。除此之外不发送其他内容。

Loggia 没有账号、没有统计分析，也没有自己的服务器。

2. 我们不收集什么

Loggia 不会收集或接收你公开的服务、你的域名、你的 Cloudflare API 令牌、访问你服务的流量，也不会收集你如何使用这个应用。一切都在你的 Mac 或你自己的 Cloudflare 账号里完成。访客通过 Cloudflare 直接访问你 Mac 上的服务。

日志只保存在你的 Mac 上。导出诊断信息会生成一个由你自己发送的文件，其中的令牌、授权码和你的用户目录已被去除。

3. 第三方服务

  • Cloudflare：Loggia 用你的令牌调用 Cloudflare API，在你的账号里管理通道、域名记录和访问保护。你的账号适用 Cloudflare 自己的隐私政策。
  • GitHub：用于下载 cloudflared，并检查它是否有新版本。
  • dl.useloggia.com：用于检查 Loggia 是否有新版本，每天一次，除非你关闭自动检查。请求里带有应用名称和版本号、更新框架的版本号以及你的 IP 地址，不发送系统配置信息。
  • 公共 DNS：用于检查你的域名是否已经生效。
  • Dodo Payments：我们的支付服务商和销售方（Merchant of Record）。结账时 Dodo 按其自身隐私政策收集你的姓名、邮箱和账单信息，并负责发票、税费和退款。Loggia 不会收到你的支付信息。
  • 本网站：静态网站，不使用 Cookie。网站和下载文件由 Cloudflare 提供，Cloudflare 会保留标准的访问日志。访问量由 Cloudflare Web Analytics 统计，它衡量页面浏览量和页面加载时间。据 Cloudflare 说明，它不使用 Cookie 或本地存储，不对访客做指纹识别，也不收集个人数据。应用本身不使用它。

4. 数据存储

  • 你的 Cloudflare API 令牌和 Pro 授权码保存在这台 Mac 的钥匙串里。
  • 设置和服务列表保存在 ~/Library/Application Support/Loggia，连接组件的日志在 ~/Library/Logs/Loggia。
  • 开发者可以在 Dodo 后台看到你的购买记录（姓名、邮箱、付款编号），仅用于提供支持和处理退款。

5. 你的权利和控制

你可以随时在“设置 › 许可”里取消激活授权码。如需了解我们持有你的哪些信息，或要求更正、删除，请发邮件到 support@useloggia.com，我们会在 30 天内回复。

如果你位于欧盟或欧洲经济区，还享有 GDPR 赋予的权利，包括数据可携权和向当地数据保护机构投诉的权利。

6. 变更

本政策如有变更，上方的日期会随之更新。

对 Loggia、购买或退款有疑问，请写信到 support@useloggia.com。
