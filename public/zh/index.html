把 Mac 上的服务，安全地放到互联网上。

Loggia 把本地端口变成你自己 Cloudflare 账户下的 HTTPS 地址，并显示每个服务是否在线。

中间没有第三方服务器

Loggia 用你自己的 Cloudflare 账户，不经过任何第三方服务器。

令牌只留在你的 Mac 上

API 令牌保存在 Mac 的钥匙串里，只会发给 Cloudflare。

App 没有统计，不用注册

设置和服务列表只保存在你的 Mac 上。只有激活 Pro 时才会发送与你有关的内容：授权码和设备标签，发给 Dodo Payments。详见隐私政策。

只让你列出的人打开

为服务开启访问保护后，访客要用发到指定邮箱的一次性验证码登录。

三步开始。

  1. 粘贴 Cloudflare API 令牌

    点「在 Cloudflare 创建 Token」，会打开一个已经勾好权限的模板。

  2. 让 Loggia 准备运行时

    它会下载 Cloudflare 的 cloudflared，并让它保持运行。

  3. 添加服务并公开

    选一个本地端口，打开「公开到互联网」，再选一个域名。
