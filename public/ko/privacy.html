개인정보 처리방침

마지막 업데이트 · 2026년 10월

이 번역은 참고용입니다. 영어 버전과 내용이 다를 경우 영어 버전이 우선합니다.

이 정책은 Loggia 앱과 이 웹사이트에 적용되며, 무엇을 수집하고 누구에게 전송하는지, 그리고 사용자가 할 수 있는 선택을 설명합니다.

1. 수집하는 정보

Pro를 활성화, 확인 또는 비활성화할 때 Loggia는 라이선스 키와 기기 이름표(Mac의 이름과 하드웨어 식별자에서 만든 짧은 코드)를 HTTPS로 Dodo Payments에 보냅니다. 그 외에는 아무것도 전송하지 않습니다.

Loggia에는 계정, 분석 도구, 자체 서버가 없습니다.

2. 수집하지 않는 정보

Loggia는 사용자가 공개한 서비스, 도메인, Cloudflare API 토큰, 서비스로 들어오는 트래픽, 앱 사용 방식을 수집하거나 받지 않습니다. 모든 것은 사용자의 Mac 또는 사용자 본인의 Cloudflare 계정에서 실행됩니다. 방문자는 Cloudflare를 거쳐 Mac으로 직접 접속합니다.

로그는 Mac에만 저장됩니다. 진단 정보를 내보내면 파일이 만들어지며, 이 파일은 사용자가 직접 보냅니다. 파일에서는 토큰, 라이선스 키, 홈 폴더 경로가 제거됩니다.

3. 제3자 서비스

  • Cloudflare: Loggia는 사용자의 토큰으로 Cloudflare API를 호출하여 사용자 계정의 터널, 도메인 레코드, 접근 보호를 관리합니다. 사용자의 계정에는 Cloudflare 자체 개인정보 처리방침이 적용됩니다.
  • GitHub: cloudflared를 다운로드하고 새 버전이 있는지 확인하기 위해 사용합니다.
  • dl.useloggia.com: Loggia의 새 버전을 확인하기 위해 하루에 한 번 사용하며, 자동 확인을 끄면 사용하지 않습니다. 요청에는 앱 이름과 버전, 업데이트 프레임워크의 버전, 사용자의 IP 주소가 포함되며 시스템 프로파일은 전송되지 않습니다.
  • 공용 DNS: 사용자의 도메인이 정상적으로 확인되는지 점검하기 위해 사용합니다.
  • Dodo Payments: 결제 대행사이자 판매 대행자(merchant of record)입니다. 결제 시 Dodo는 Dodo의 개인정보 처리방침에 따라 이름, 이메일 주소, 청구 정보를 수집하고 청구서, 세금, 환불을 처리합니다. Loggia는 결제 정보를 받지 않습니다.
  • 이 웹사이트: 정적 사이트이며 쿠키를 사용하지 않습니다. 웹사이트와 다운로드 파일은 Cloudflare가 제공하며, Cloudflare는 일반적인 접속 로그를 보관합니다. 방문 수는 Cloudflare Web Analytics로 집계하며, 페이지 조회 수와 페이지 로드 시간을 측정합니다. Cloudflare의 설명에 따르면 쿠키나 로컬 저장소를 사용하지 않고, 방문자를 핑거프린팅하지 않으며, 개인 데이터를 수집하지 않습니다. 앱 자체는 이를 사용하지 않습니다.

4. 데이터 저장

  • Cloudflare API 토큰과 Pro 라이선스 키는 Mac의 키체인에 저장됩니다.
  • 설정과 서비스 목록은 ~/Library/Application Support/Loggia에, 커넥터의 로그는 ~/Library/Logs/Loggia에 저장됩니다.
  • 개발자는 Dodo 대시보드에서 사용자의 구매 기록(이름, 이메일 주소, 결제 ID)을 볼 수 있으며, 지원과 환불 처리에만 사용합니다.

5. 사용자의 권리와 통제

설정 › 라이선스에서 언제든지 라이선스를 비활성화할 수 있습니다. 당사가 보유한 사용자 정보를 확인하거나 정정 또는 삭제를 요청하려면 support@useloggia.com로 이메일을 보내십시오. 30일 이내에 답변합니다.

EU 또는 EEA에 거주하는 경우 GDPR이 보장하는 권리(데이터 이동권, 관할 개인정보 보호 감독 기관에 불만을 제기할 권리 포함)도 가집니다.
