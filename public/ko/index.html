중간 서버 없음

Loggia는 내 Cloudflare 계정에서 동작하며, 중간에 제3자 서버가 없습니다.

토큰은 Mac에만 저장

API 토큰은 Mac의 키체인에 보관되며 Cloudflare에만 전송됩니다.

앱에 분석 도구 없음, 가입 없음

설정과 서비스 목록은 Mac에 남습니다. Pro를 활성화할 때만 사용자에 관한 정보가 전송되며, 라이선스 키와 기기 이름표가 Dodo Payments로 갑니다. 개인정보 처리방침을 참고하십시오.

지정한 사람만 접속

서비스에 접근 보호를 켜면, 방문자는 허용한 이메일로 받은 일회용 코드로 로그인합니다.

세 단계로 설정합니다.

  1. Cloudflare API 토큰 붙여넣기

    “Cloudflare에서 토큰 만들기”를 누르면 권한이 미리 선택된 템플릿이 열립니다.

  2. Loggia가 런타임 준비

    Cloudflare의 cloudflared를 다운로드하고 계속 실행되도록 관리합니다.

  3. 서비스를 추가하고 공개

    로컬 포트를 고른 다음 ‘인터넷에 공개’을 켜고 도메인을 선택합니다.
