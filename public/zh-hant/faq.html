常見問題

找不到答案？App 本身會告訴你哪裡出了問題、按哪個按鈕可以修復。請先打開服務或連線路徑的詳細資訊看看。

基本資訊

Loggia 免費嗎？

免費版是免費的，最多可以發布 2 個服務到網際網路，但無法開啟新的存取保護。Pro 取消這些限制，一次買斷。詳見價格。

需要準備什麼？

一台 macOS 26 或更新版本的 Mac、一個 Cloudflare 帳戶，以及至少一個由 Cloudflare 管理的網域。

需要付費給 Cloudflare 嗎？

發布服務使用的是 Cloudflare Tunnel，它是免費的。存取保護需要帳戶設定好 Zero Trust，免費方案就夠用。網域照常由註冊商收費。

Mac 需要一直開著嗎？

需要。服務一直在你的 Mac 上執行，Loggia 只是給它們一個公開位址。Mac 進入睡眠、關機或離線時，就無法連到這個位址。連接器會在登入時自動啟動，Mac 恢復後服務也會跟著恢復。

我的流量會經過你們的伺服器嗎？

不會。訪客經由 Cloudflare 直接連到你 Mac 上的服務。Loggia 沒有自己的伺服器，也看不到你的流量。詳見隱私權政策。

Cloudflare 與 API 權杖

API 權杖需要哪些權限？

在初始設定或「設定 › Cloudflare」中按 在 Cloudflare 建立權杖，會開啟一個已經勾選好權限的範本，只要確認即可。範本包含：

Account › Cloudflare Tunnel › Edit必要
Zone › DNS › Edit必要。Zone Resources 可以只選你要用的網域。
Account › Access: Apps and Policies › Edit選用，用於存取保護
Account › Access: Organizations, Identity Providers, and Groups › Edit選用，讓 Loggia 替你設定電子郵件驗證碼登入

如果想自己建立權杖，「設定 › Cloudflare」中逐項列出了權限，並提供 拷貝權限清單。權杖只儲存在 Mac 的鑰匙圈中。

我剛修正了權杖的權限，Loggia 還是顯示缺少權限。

Cloudflare 上的變更需要一兩分鐘才會生效。稍等一下，再到「設定 › Cloudflare」按 再檢查一次。

為什麼無法開啟存取保護？
  • 存取保護是 Pro 功能。
  • 服務要先發布。
  • 權杖需要具備上方列出的兩項 Access 權限。
  • Cloudflare 帳戶需要設定好 Zero Trust，免費方案就夠用。設定完成後，到「設定 › Cloudflare」按 再檢查一次。
開啟存取保護後，誰可以開啟我的服務？

只有你列出的電子郵件地址；如果加入 @example.com，則允許該網域下的所有人。訪客會透過電子郵件收到一次性驗證碼。登入預設有效 24 小時，可以調整。

Pro 還可以加入信任的網路，例如住家或辦公室的網際網路位址。從信任的網路開啟時不需要驗證碼，同一個 Wi-Fi 或行動網路上的其他人也一樣。

Loggia 會覆寫我已經在用的網域嗎？

不會在你不知情的情況下覆寫。如果網域已經指向其他地方，Loggia 會停下來，先詢問你再做任何變更。

Pro 與授權

一組授權碼可以用在幾台 Mac 上？

兩台。想換到另一台 Mac，請先在已啟用的其中一台 Mac 上，到「設定 › 授權」按 停用。

Pro 需要連上網路嗎？

啟用時需要。之後 Loggia 每天驗證一次授權。如果連不上授權伺服器，Pro 從上次驗證成功起還能繼續使用 30 天，Mac 重新連上網路後會自動恢復。

授權碼涵蓋哪些版本？

1.x 的所有版本。更新本身在免費版和 Pro 都是免費的。

可以退款嗎？

可以，購買後 14 天內都可以申請。退款政策說明了如何申請，以及授權碼會怎樣。

退款後，或授權失效後會怎樣？

Loggia 會回到免費版，但不會讓任何東西下線：已經發布的服務會繼續執行。免費版只管理列表中最早發布的 2 個服務；其他服務會繼續執行，但 Loggia 不再檢查它們，並顯示為 未管理，你仍然可以停止發布它們。已經開啟的存取保護會繼續生效，你可以關閉它，但無法修改。再次升級到 Pro 後，一切都會恢復。

疑難排解

服務顯示無法連線，要從哪裡開始查？

打開這個服務。Loggia 會顯示連線路徑的哪一段中斷了（本機服務、網域記錄、Mac 上的連接器，或是 Cloudflare）、原因是什麼，以及按哪個按鈕可以修復。新的網域記錄可能需要幾分鐘才會生效。

Loggia 提示有代理軟體攔截了連線。

代理軟體在增強模式或 TUN 模式下開著 Fake-IP 時，會給 argotunnel.com 回傳假位址，cloudflared 到 Cloudflare 最多只能維持兩條連線，甚至連不上。cloudflared 無法連到 Cloudflare 時，Loggia 會檢查這一點，確認之後才提到代理軟體。請在代理軟體中：

  1. 將 argotunnel.com 和 cftunnel.com 設為直連。
  2. 將 +.argotunnel.com 加入 Fake-IP 過濾（fake-ip-filter），讓它解析到 Cloudflare 的真實位址。Fake-IP 模式下只設直連還不夠。
  3. 按 Loggia 顯示的 重新連接、再試一次 或 重新啟動。

公開服務的狀態是從外網檢查的，不受代理軟體影響。如果剛發布的網域在別處能開啟、在這台 Mac 上卻打不開，可能是代理軟體把它記成了不存在，最長半小時：把這個網域也加入 Fake-IP 過濾，或清除一次代理軟體的 DNS 快取。

在哪裡可以看到連接器的狀態？

「設定 › 連接器」會顯示 cloudflared 是否已安裝、是否在執行、版本、上次的結束代碼，以及記錄檔。如果一直出錯，可以在那裡匯出診斷資訊。

更新與解除安裝

如何更新 Loggia？

Loggia 每天會檢查一次新版本。有新版本時，會顯示更新內容，並可以幫你下載、安裝及重新啟動。想立即檢查，請在「設定 › 關於」中按 檢查更新；若要停止每天檢查，請在同一處關閉 自動檢查更新。你的設定和服務都會保留，免費版和 Pro 都可以免費更新。每個版本的變更請見更新記錄。

如何完整解除安裝 Loggia？
  1. 在「設定 › Cloudflare」中按 全部移除…，從 Cloudflare 刪除 Loggia 建立的網域記錄、路由和存取保護。
  2. 結束 Loggia，把它從「應用程式」移到垃圾桶。
  3. 在「終端機」中執行 launchctl bootout gui/$(id -u)/com.useloggia.app.cloudflared，然後刪除 ~/Library/Application Support/Loggia、~/Library/Logs/Loggia 和 ~/Library/LaunchAgents/com.useloggia.app.cloudflared.plist。
  4. 在「鑰匙圈存取」中刪除「Loggia」項目。
