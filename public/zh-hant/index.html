Loggia 把本機連接埠變成你自己 Cloudflare 帳戶下的 HTTPS 位址，並顯示每個服務是否在線上。

只用你自己的帳戶。

中間沒有第三方伺服器

Loggia 使用你自己的 Cloudflare 帳戶，不經過任何第三方伺服器。

權杖只留在你的 Mac 上

API 權杖儲存在 Mac 的鑰匙圈中，只會傳送給 Cloudflare。

App 沒有統計，不用註冊

設定和服務列表只儲存在你的 Mac 上。只有啟用 Pro 時才會傳送與你有關的內容：授權碼和裝置標籤，傳送給 Dodo Payments。詳見隱私權政策。

只讓你列出的人開啟

為服務開啟存取保護後，訪客要用寄到指定電子郵件的一次性驗證碼登入。

三個步驟完成設定。

  1. 貼上 Cloudflare API 權杖

    按「在 Cloudflare 建立權杖」，會開啟一個已經勾選好權限的範本。

  2. 讓 Loggia 準備執行環境

    它會下載 Cloudflare 的 cloudflared，並讓它持續執行。

  3. 新增服務並發布

    選一個本機連接埠，開啟「發布到網際網路」，再選一個網域。
