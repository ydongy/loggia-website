隱私權政策

最後更新 · 2026 年 10 月

本頁譯文僅供參考；如與英文版本不一致，以英文版本為準。

本政策適用於 Loggia App 和本網站：收集什麼、傳送給誰，以及你有哪些選擇。

1. 我們收集什麼

啟用、驗證或停用 Pro 時，Loggia 會透過 HTTPS 向 Dodo Payments 傳送授權碼和一個裝置標籤（你的 Mac 名稱加上一段由硬體識別碼算出的短碼）。除此之外不會傳送其他內容。

Loggia 沒有帳戶、沒有分析統計，也沒有自己的伺服器。

2. 我們不收集什麼

Loggia 不會收集或接收你發布的服務、你的網域、你的 Cloudflare API 權杖、連到你服務的流量，也不會收集你如何使用這個 App。一切都在你的 Mac 或你自己的 Cloudflare 帳戶中完成。訪客透過 Cloudflare 直接連到你 Mac 上的服務。

記錄檔只保存在你的 Mac 上。匯出診斷資訊會產生一個由你自行傳送的檔案，其中的權杖、授權碼和你的個人資料夾路徑都已移除。

3. 第三方服務

  • Cloudflare：Loggia 以你的權杖呼叫 Cloudflare API，在你的帳戶中管理通道、網域記錄和存取保護。你的帳戶適用 Cloudflare 自己的隱私權政策。
  • GitHub：用於下載 cloudflared，並檢查它是否有新版本。
  • dl.useloggia.com：用於檢查 Loggia 是否有新版本，每天一次，除非你關閉自動檢查。請求中帶有 App 名稱和版本號、更新框架的版本號以及你的 IP 位址，不傳送系統設定檔資訊。
  • 公用 DNS：用於檢查你的網域是否已經生效。
  • Dodo Payments：我們的付款服務商和銷售方（Merchant of Record）。結帳時，Dodo 依其自身的隱私權政策收集你的姓名、電子郵件地址和帳單資料，並負責發票、稅款和退款。Loggia 不會收到你的付款資料。
  • 本網站：靜態網站，不使用 Cookie。網站和下載檔案由 Cloudflare 提供，Cloudflare 會保留標準的存取記錄。造訪量由 Cloudflare Web Analytics 統計，它衡量頁面瀏覽量和頁面載入時間。依 Cloudflare 的說明，它不使用 Cookie 或本機儲存空間，不對訪客做指紋辨識，也不收集個人資料。應用程式本身不使用它。

4. 資料儲存

  • 你的 Cloudflare API 權杖和 Pro 授權碼保存在這台 Mac 的鑰匙圈中。
  • 設定和服務清單保存在 ~/Library/Application Support/Loggia，連線元件的記錄檔在 ~/Library/Logs/Loggia。
  • 開發者可以在 Dodo 後台看到你的購買紀錄（姓名、電子郵件地址、付款編號），僅用於提供支援和處理退款。

5. 你的權利和控制

你可以隨時在「設定 › 授權」中停用授權碼。如需了解我們持有你的哪些資料，或要求更正、刪除，請寄信到 support@useloggia.com，我們會在 30 天內回覆。

如果你位於歐盟或歐洲經濟區，還享有 GDPR 賦予的權利，包括資料可攜權，以及向當地資料保護機關申訴的權利。

6. 變更

本政策如有變更，上方的日期會隨之更新。

對 Loggia、購買或退款有疑問，請寫信到 support@useloggia.com。
