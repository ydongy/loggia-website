Nur Ihr eigenes Konto.

Keine Server dazwischen

Loggia arbeitet mit Ihrem Cloudflare-Konto, ohne Server von Dritten dazwischen.

Ihr Token bleibt auf Ihrem Mac

Das API-Token liegt im Schlüsselbund Ihres Mac und wird nur an Cloudflare gesendet.

Keine Analyse in der App, keine Registrierung

Einstellungen und Dienstliste bleiben auf Ihrem Mac. Nur beim Aktivieren von Pro wird etwas über Sie gesendet: ein Lizenzschlüssel und eine Gerätebezeichnung, an Dodo Payments. Siehe Datenschutzerklärung.

Nur die Personen auf Ihrer Liste

Schalten Sie für einen Dienst den Zugriffsschutz ein. Besucher melden sich dann mit einem Einmalcode an, der an eine von Ihnen freigegebene E-Mail-Adresse geht.

In drei Schritten eingerichtet.

  1. Cloudflare-API-Token einfügen

    „Token bei Cloudflare erstellen“ öffnet eine Vorlage, in der die Berechtigungen bereits ausgewählt sind.

  2. Loggia die Laufzeitumgebung einrichten lassen

    Loggia lädt cloudflared von Cloudflare herunter und hält es für Sie am Laufen.

  3. Dienst hinzufügen und veröffentlichen

    Wählen Sie einen lokalen Port, schalten Sie dann „Im Internet veröffentlichen“ ein und wählen Sie eine Domain.
