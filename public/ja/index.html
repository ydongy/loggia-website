Mac 上のサービスを、安全にインターネットへ。

Loggia は、ローカルのポートをご自身の Cloudflare アカウント上の HTTPS アドレスにし、各サービスが動いているかを表示します。

経路の一部が止まっています。どこが止まっているかを Loggia が表示します。

公開していない状態です。異常ではありません。

使うのはご自身のアカウントだけです。

間にサーバーを挟みません

Loggia はご自身の Cloudflare アカウント上で動きます。間に第三者のサーバーはありません。

トークンは Mac に保存されます

API トークンは Mac のキーチェーンに保存され、Cloudflare にだけ送信されます。

アプリにアクセス解析なし、アカウント登録なし

設定とサービス一覧は Mac に保存されます。お客様に関する情報が送信されるのは Pro を有効化するときだけで、ライセンスキーとデバイス名が Dodo Payments に送られます。プライバシーポリシーをご覧ください。

指定した人だけが開けます

サービスのアクセス保護をオンにすると、訪問者は許可したメールアドレスに届くワンタイムコードでログインします。

3 つの手順で設定できます。

  1. Cloudflare の API トークンを貼り付ける

    「Cloudflare でトークンを作成」を押すと、必要な権限があらかじめ選択されたテンプレートが開きます。

  2. Loggia に実行環境を準備させる

    Cloudflare の cloudflared をダウンロードし、動かし続けます。

  3. サービスを追加して公開する

    ローカルのポートを選び、「インターネットに公開」をオンにしてドメインを選びます。

Loggia をダウンロード

ダウンロードできるのは無料版です。Pro は買い切りで、サブスクリプションではありません。

macOS 26 以降に対応しています。

ダウンロード Pro を購入

公式のダウンロードは useloggia.com のみです。ほかの場所のインストーラは改ざんされている可能性があります。

決済は Dodo Payments が処理し、ライセンスキーはメールで届きます。


確認するには、ダウンロードしたファイルに対する shasum -a 256 の出力と比べてください。
