プライバシーポリシー

最終更新 · 2026年10月

この翻訳は参考用です。英語版と内容が異なる場合は、英語版が優先されます。

このポリシーは Loggia アプリとこのウェブサイトに適用されます。何を収集し、誰に送信し、どのような選択肢があるかを説明します。

1. 収集する情報

Pro を有効化、確認、または無効化するとき、Loggia はライセンスキーとデバイス名（お使いの Mac の名前と、ハードウェア識別子から作られた短いコード）を、HTTPS で Dodo Payments に送信します。送信する情報はこれだけです。

Loggia にはアカウントも、分析機能も、独自のサーバーもありません。

2. 収集しない情報

Loggia は、公開しているサービス、ドメイン、Cloudflare API トークン、サービスに届く通信、アプリの使い方を、収集することも受け取ることもありません。すべてお使いの Mac 上、またはご自身の Cloudflare アカウント内で動作します。訪問者は Cloudflare を経由して、お使いの Mac のサービスに直接アクセスします。

ログはお使いの Mac に残ります。診断情報を書き出すと、ご自身で送信するファイルが作られます。トークン、ライセンスキー、ホームフォルダのパスは取り除かれます。

3. 第三者のサービス

  • Cloudflare：Loggia はお客様のトークンを使って Cloudflare API を呼び出し、お客様のアカウント内のトンネル、ドメインレコード、アクセス保護を管理します。お客様のアカウントには Cloudflare 自身のプライバシーポリシーが適用されます。
  • GitHub：cloudflared をダウンロードし、新しいバージョンがあるか確認するために使います。
  • dl.useloggia.com：Loggia の新しいバージョンを確認するために使います。自動確認をオフにしない限り、1 日に 1 回です。リクエストには、アプリ名とバージョン、アップデートフレームワークのバージョン、お客様の IP アドレスが含まれ、システムプロファイルは送信されません。
  • 公開 DNS：ドメインが名前解決できるか確認するために使います。
  • Dodo Payments：当方の決済事業者であり、販売代行者（merchant of record）です。決済時に、Dodo は氏名、メールアドレス、請求先情報を自社のプライバシーポリシーに基づいて収集し、請求書、税金、返金を処理します。Loggia が決済情報を受け取ることはありません。
  • このウェブサイト：静的サイトで、Cookie は使いません。サイトとダウンロードは Cloudflare から配信され、Cloudflare は標準的なアクセスログを保持します。訪問数は Cloudflare Web Analytics で集計しており、ページビューとページの読み込み時間を計測します。Cloudflare の説明によると、Cookie やローカルストレージは使わず、訪問者のフィンガープリントも個人データの収集も行いません。アプリ自体はこれを使いません。

4. データの保存

  • Cloudflare API トークンと Pro ライセンスキーは、お使いの Mac のキーチェーンに保存されます。
  • 設定とサービス一覧は ~/Library/Application Support/Loggia に、コネクタのログは ~/Library/Logs/Loggia に保存されます。
  • 開発者は、Dodo のダッシュボードで購入記録（氏名、メールアドレス、支払い ID）を確認できます。目的は、サポートの提供と返金の処理に限ります。

5. お客様の権利と管理

設定 › ライセンス から、いつでもライセンスを無効化できます。当方が保有するお客様の情報について確認、訂正、削除を希望する場合は、support@useloggia.com にメールでご連絡ください。30 日以内に返信します。

EU または EEA にお住まいの場合は、データポータビリティや、所在地のデータ保護当局に苦情を申し立てる権利など、GDPR が定める権利もあります。

6. 変更

本ポリシーを変更した場合は、上の日付も更新します。

Loggia、購入、返金についてのお問い合わせは support@useloggia.com までメールでどうぞ。
