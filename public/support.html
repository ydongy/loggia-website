Support

Something not working, or an idea to share? Write to us. We read every message.

Email us

Write to support@useloggia.com. In Loggia, choose Help › Send Feedback… and a new message opens with your Loggia and macOS versions already filled in.

What to tell us

  • What you were trying to do.
  • What happened instead, and any message you saw.
  • Your Loggia and macOS versions, if you did not use Send Feedback.

Send diagnostics

If something keeps failing, choose Help › Export Diagnostics… (or Settings › Connector › Export…). Loggia saves a zip file and shows it in Finder; attach it to your email. Tokens and your license key are removed and your home folder is shortened to ~. Loggia never sends the file by itself.

Before you write

The FAQ answers the common questions, including what to do when a service is down. For a refund, see the Refund Policy.

Security

To report a security problem, write to the same address with “Security” in the subject, and please do not post it publicly.
